# Scale Lab

You can study System Design through tutorials and courses covering key systems and common problems —or even, at times, by building simple systems from scratch. In a real-world project, however, the standard approach —or at least, the recommended one— is to start with the simplest solutions and refine it based on actual usage.

Often, the intended design—or the one that would theoretically be most suitable—for a project is never actually implemented, whether due to various constraints or simply because the existing design is already sufficient.

This project was created to analyze how a system's design evolves under load within the context of the following project description:

> Design and build an event-processing service that allows external devices or services to send their events in real time, so that they can be processed in a decoupled manner.
